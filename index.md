
# Obsidian GSync - Personal OAuth Connector

This website describes a personal Google OAuth configuration used with the open-source GSync plugin for Obsidian.

This is not the official GSync website or a publicly offered synchronization service.

## Purpose

GSync synchronizes selected Obsidian vault files between Windows, iPhone, and Google Drive using the Google Drive API.

The OAuth client is configured for personal use on my own devices.
