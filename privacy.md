# Privacy Policy

Last updated: October 31, 2026

## 1. Overview

This website describes a personal Google OAuth configuration used with GSync, an open-source Obsidian community plugin.

This configuration is for personal use and is not an official GSync service.

## 2. Google Drive Access

GSync requests the Google Drive scope:

https://www.googleapis.com/auth/drive

This scope technically allows broad access to Google Drive.

According to the GSync project documentation, the plugin uses this permission to list, read, upload, update, download, and trash files within the configured synchronization folder.

## 3. Data Processing

Files are transferred directly between the user's device and Google Drive through Google's API.

The personal OAuth configuration does not operate an additional synchronization server.

GSync's project documentation states that it does not use analytics, advertisements, or telemetry.

## 4. Credential Storage

OAuth credentials and refresh tokens are stored locally in the Obsidian plugin configuration on the user's device.

These credentials must not be published or shared.

## 5. Data Sharing

This personal OAuth configuration does not independently collect or sell Google user data.

Google Drive data is processed through Google's services and the locally installed GSync plugin.

## 6. User Control

Users can revoke OAuth access in their Google Account settings:

https://myaccount.google.com/permissions

Local files and cloud files remain subject to the user's own storage and deletion settings.

## 7. Third-Party Software

GSync is an independent, open-source Obsidian plugin.

Source code and additional documentation:

https://github.com/dg0988/ObsidianGSync

## 8. Changes

This privacy policy may be updated if the personal OAuth configuration or its data handling changes.
